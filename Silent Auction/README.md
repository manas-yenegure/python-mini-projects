# Silent Auction

A simple Python console application that simulates a **silent auction**. Multiple users can enter their names and bid amounts, and the program automatically determines the highest bidder and announces the winner.

## Features

- Accepts bids from multiple participants.
- Stores all bids using a Python dictionary.
- Determines the highest bidder automatically.
- Displays the winner and the winning bid.
- Beginner-friendly project demonstrating core Python concepts.

## Built With

- Python 3

## Concepts Used

This project covers the following Python concepts:

- Dictionaries
- Loops (`while` and `for`)
- Conditional Statements (`if`)
