# Quiz brain

A simple command-line **True/False Quiz** built with Python. The program asks the player a series of True/False questions and keeps track of the score throughout the quiz.

This project was created as part of my Python learning journey to practice **Object-Oriented Programming (OOP), classes, lists, loops, functions, and conditional statements**.

## Features

* Multiple **True/False** questions
* Questions stored separately in `data.py`
* Uses a **Question class** to store question data
* Automatically checks the player's answers
* Displays whether the answer is **Correct** or **Wrong**
* Shows the correct answer after each question
* Displays the current score after each question
* Shows the final score when the quiz is completed
