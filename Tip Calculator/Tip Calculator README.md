# Tip Calculator

A simple command-line Python application that calculates the tip amount and splits the total bill equally among a group of people.

## 📖 Description

The Tip Calculator allows users to enter the total bill amount, choose a tip percentage, and specify the number of people sharing the bill. It then calculates how much each person should pay, making bill splitting quick and easy.

## ✨ Features

- Calculate tip based on a chosen percentage
- Split the bill among multiple people
- Display the amount each person should pay
- Simple and beginner-friendly command-line interface
