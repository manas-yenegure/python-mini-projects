# ✊✋✌️ Rock Paper Scissors Game

A simple command-line **Rock Paper Scissors** game developed in **Python**.

The player chooses Rock, Paper, or Scissors, and the computer randomly makes its choice. The winner is decided according to the classic game rules.
## Features

- User vs Computer gameplay
- Random computer choice using Python's `random` module
- Instant win/lose/draw result
- Input validation for invalid choices
- Beginner-friendly and easy-to-understand code
- Optional ASCII art for a better terminal experience


## 🛠️ Technologies Used

- Python 3
- Random Module

## How to Run

1. Clone this repository.

```bash
git clone https://github.com/manas-yenegure/Rock-Paper-Scissors.git 
```

2. Navigate to the project folder.

```bash
cd Rock-Paper-Scissors
```

3. Run the Python file.

```bash
python main.py
```
