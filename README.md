#  Python Mini Projects

A collection of beginner-friendly Python mini projects built while learning Python. This repository serves as a portfolio of practical exercises and applications that demonstrate core Python programming concepts.

## 📖 About

This repository contains a variety of Python mini projects organized into separate folders. Each project is self-contained and includes its own source code and documentation.

The purpose of this repository is to:

- Practice Python programming
- Improve problem-solving skills
- Build hands-on projects
- Strengthen programming fundamentals
- Track my learning journey

## 🛠️ Skills Covered

- Variables and Data Types
- User Input and Output
- Conditional Statements
- Loops
- Functions
- Lists, Tuples, and Dictionaries
- String Manipulation
- Modules and Packages
- Random Module
- File Handling
- Basic Algorithms
- Problem Solving
