# Band Name Generator

A simple Python project that generates a fun band name by combining the name of the city you grew up in with your pet's name.

## Features

- Takes user input
- Generates a unique band name
- Beginner-friendly Python project

## Technologies Used

- Python 3

## How to Run

1. Open the project folder.
2. Run:
```bash
python main.py
```

## Example
```
Welcome to the Band Name Generator!

What's the name of the city you grew up in?
Pune

What's your pet's name?
Bruno

Your band name could be Pune Bruno
```
